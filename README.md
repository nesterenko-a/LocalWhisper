# Локальный Whisper

Транскрибатор на faster-whisper с локальным интерфейсом Gradio: аудио/видео, запись с микрофона, русский и другие языки, разделение по спикерам, TXT/SRT/VTT/JSON.

[Быстрый старт](QUICKSTART.md) · [Разработка](CONTRIBUTING.md)

Задачи выполняются в серверной очереди независимо от вкладки браузера. После повторного открытия страницы восстанавливаются последняя задача, прогресс и промежуточный текст. Есть выбор задачи из истории; готовые результаты сохраняются после перезапуска сервера. Исходные записи и метаданные хранятся локально в `jobs/` (исключена из Git). Остановка сервера прерывает незавершённые задачи; автоматического продолжения после остановки сервера нет.

Состояние сохраняется атомарно через отдельный временный файл. Кратковременные блокировки файлов Windows обрабатываются повторными попытками; прогресс записывается не чаще раза в секунду. Если диск остаётся недоступным, распознавание продолжает работать, в статусе появляется предупреждение, а сохранение повторяется в фоне. До исчезновения предупреждения не выключайте сервер: последние данные ещё могут находиться только в памяти.

На вкладках файлов и микрофона есть кнопки «Остановить распознавание». Они отменяют выбранную в истории задачу, сохраняя полученный текст и `partial.txt`. Отмена задачи в очереди предотвращает её запуск. Для остановки активного вычисления завершается отдельный процесс задачи; сервер продолжает работать и запускает следующую задачу. При включённых спикерах частичный текст сохраняет уже полученную разметку голосов. Отмена не поддерживает продолжение с места остановки — запись нужно отправить заново.

В разделе «Текст» реплики отображаются отдельными блоками: у спикеров постоянные цвета, у каждой реплики есть имя и временной интервал. Над текстом показан список участников. Цвет связан с исходным номером спикера и не меняется после переименования. В разделе «Обычный текст — копирование» доступна текстовая версия с кнопкой копирования. Для старых задач без структурированных отметок показываются абзацы без выдуманных временных меток. Оформление не меняет содержимое TXT/SRT/VTT/JSON.

## Запуск на Windows

1. Установите Python 3.11–3.13 (с добавлением в PATH).
2. Запустите `start.bat`. При первом запуске установятся зависимости.
3. Откроется http://127.0.0.1:7860. Выберите файл или запишите голос, затем нажмите «Распознать».

При первом выборе каждой модели она скачивается с Hugging Face. Затем доступна без интернета; флажок «Только офлайн» запрещает скачивание. Аудио не отправляется в облачный сервис распознавания. Модели находятся в `models/`, результаты в отдельных папках `output/`. Браузер должен иметь разрешение на микрофон. Запись распознаётся после остановки и нажатия кнопки, не потоково. Для остановки сервера нажмите Ctrl+C в его окне.

Модель `small` выбрана по умолчанию; на медленном CPU попробуйте `base` или `tiny`. Более крупные модели требуют больше памяти и времени. Язык «Авто» позволяет распознавать и другие языки Whisper. Результат можно скопировать или скачать.

## Спикеры, имена и должности

Перед запуском включите «Спикеры → Разделять по спикерам». Можно задать максимум участников, либо оставить 0 без ограничения. Это верхняя граница, а не требование найти указанное количество в каждом буфере. Whisper получает временные отметки слов; sherpa-onnx разделяет голоса с помощью моделей pyannote segmentation 3.0 и WeSpeaker ResNet34. Слова связываются с голосами по наибольшему пересечению временных интервалов. Голоса нумеруются по первому появлению в этой записи: `Спикер 1`, `Спикер 2`. Если голос для слова не определён, выводится `Спикер неизвестен`. Разделение голосов выполняется на CPU независимо от выбранного устройства Whisper.

После чтения аудио запись обрабатывается буферами размером около 5% длительности, минимум 30 и максимум 120 секунд. Сначала определяются голоса первого буфера; затем Whisper распознаёт его текст, пока отдельный процесс определяет голоса следующего. Заранее готовится только один следующий буфер. На границах добавлено по 2 секунды контекста; слова относятся к буферу по середине временного интервала, чтобы уменьшить пропуски и повторы. Все временные отметки переводятся в шкалу исходной записи. Полное декодированное аудио пока хранится в памяти.

Голоса между буферами сопоставляются по нормализованным голосовым векторам WeSpeaker: косинусное сходство не ниже 0.55, один локальный кластер на одного известного спикера в буфере. Для новых голосов создаются новые номера; при исчерпанном максимуме и слабом совпадении ставится «Спикер неизвестен». Это эвристика: короткие реплики, шум и похожие голоса могут дать лишние номера или неправильное сопоставление.

После распознавания текста выполняется финальная диаризация всей записи. Слова повторно сопоставляются с голосами без повторного запуска Whisper. Номера и цвета по возможности сохраняются по наибольшему временному пересечению с предварительными репликами, но при исправлении ошибок состав и границы спикеров могут измениться. При заданном максимуме лишние глобальные кластеры помечаются неизвестными. Имена повторно проверяются по уточнённым репликам. Промежуточный текст остаётся доступен во время финального анализа; обновлённые TXT/SRT/VTT/JSON формируются по итоговой разметке. Если финальный анализ не нашёл ни одного определённого спикера, сохраняется предварительная разметка. Дополнительный анализ увеличивает полное время обработки и не гарантирует улучшение на каждой записи.

Цветные реплики и временные отметки появляются по мере распознавания и восстанавливаются после повторного открытия страницы. Самопредставления уточняют имена по мере поступления текста. Первые 90% прогресса отражают обработанную длительность, оставшиеся 10% — финальное уточнение; это не прогноз оставшегося времени. На слабом CPU одновременные модели могут конкурировать за ресурсы; ускорение всей задачи не гарантируется. Микрофон обрабатывается после остановки записи, а не во время записи.

При первом включении модели спикеров скачиваются из официальных релизов [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) в `models/speakers/`, затем работают офлайн. Аудио остаётся локально. Модели требуют примерно 33 МБ загрузки, распакованные занимают больше. Время обработки увеличивается; точность зависит от записи, похожих голосов и наложения речи. Это разметка говорящих внутри записи, а не установление личности человека по голосу.

Явное русское самопредставление «Меня зовут Алексей.» или «Моё имя Алексей.» даёт имя автоматически, если не найден конфликт. Это простое правило по распознанному тексту, которое может ошибаться при цитировании или неверной транскрипции. Оно не выполняет полноценный смысловой анализ разговора. Обращения по имени/должности показываются как подсказки, без автоматического присвоения адресату. Проверяйте имена по записи.

После завершения задачи откройте «Имена и должности спикеров» и задайте, например:

```text
Спикер 1 = Алексей
Спикер 2 = Руководитель проекта
```

Нажмите «Применить имена к выбранной задаче». Изменятся все реплики выбранного спикера, TXT/SRT/VTT/JSON и сохранённая история. Исходные номера остаются в скобках: `Алексей (Спикер 1): ...`. Чтобы вернуть номер, задайте пустое имя: `Спикер 1 =`. Строки других спикеров можно не указывать — их имена сохранятся.

JSON содержит структурированные реплики, временные отметки, номера спикеров, имена и подсказки. Уже завершённые задачи без разделения голосов нужно запустить повторно с включённой опцией. Автоматического сопоставления голосов между разными записями нет.

## Перенос на другой компьютер и GPU

Для выключения используйте `stop.bat` (рядом должен быть `stop.ps1`) или Ctrl+C в окне сервера. Текущее распознавание прервётся. Закрытие браузера не останавливает сервер.

Скопируйте проект без `.venv`; при необходимости также `models/` для работы офлайн. Виртуальное окружение `.venv` создаётся заново. `setup.bat` устанавливает или восстанавливает закреплённые зависимости из `requirements-lock.txt`.

В интерфейсе выберите **NVIDIA GPU (CUDA)**. Настройка применяется при следующем распознавании. Требуются совместимая NVIDIA GPU, драйвер, CUDA 12 / cuBLAS и cuDNN 9, библиотеки которых доступны через PATH. Подробнее: https://github.com/SYSTRAN/faster-whisper#gpu . Старые GPU, включая GT 520, для этого режима не подходят; используйте CPU. AMD/Intel GPU этой сборкой не поддерживаются. Ошибка CUDA не переключает устройство автоматически — можно выбрать CPU вручную.

Интерфейс доступен только на этом компьютере (127.0.0.1), публичная ссылка не создаётся. Для декодирования файлов используется PyAV, отдельная установка ffmpeg обычно не нужна.
